# Open desktop configuration with a keyboard shortcut

## Problem and value
Desktop configuration is reachable through the sidebar gear but lacks the familiar platform shortcut. A keyboard path makes workstation settings available from the workspace, including while a terminal or input has focus.

## Scope
Add Cmd+, on macOS and Ctrl+, on Windows/Linux to the desktop renderer. Open the same General / User profile page as the Settings button when configuration is closed. Preserve the current category and unsaved values when configuration is already open. Show the shortcut on the Settings control and document it.

The browser client, native menu, system-wide shortcut registration, configurable keymaps, and settings redesign are out of scope.
