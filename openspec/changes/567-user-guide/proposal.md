# Create a user guide in /docs

## Why

The repository has engineering references and a detailed Desktop reference, but no single task-oriented path for a new Sectile user. Issue #567 lists the setup and daily workflow steps that need one discoverable guide.

## What Changes

- Add a user guide under `/docs` covering browser sign-in, personal Jira credentials and sealing, existing and new projects, workstation pairing, agent setup, Claude Code prompts, autonomous pickup, and Desktop use and configuration.
- Link the guide from the root README and the `/docs` index.
- Use current product terminology and link to detailed references for platform-specific or advanced settings.

## Scope

Documentation only. No UI, API, workflow, installation, or credential behavior changes.

## Impact

A user can move from signing in to a reviewed pull request using one guide without confusing server project settings, personal tracker credentials, and local workstation mappings.
