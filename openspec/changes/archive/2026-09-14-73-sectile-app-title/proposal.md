# Sectile desktop app title

## Why
Issue #73 requests Sectile in the app title. The web app already uses Sectile, but the desktop document, native window and header still display Sectile Local.

## What Changes
- Display Sectile Local in the desktop document, native window and header.
- Use S for the adjacent brand badge and update the desktop README heading.

## Scope
Preserve the Local suffix. Package names, executable paths, storage, environment variables and other desktop copy are outside this title-only correction.

## Impact
Desktop presentation only; no API or data changes. No unresolved requirements or external implementation dependencies.
