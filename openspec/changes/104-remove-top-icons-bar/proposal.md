# Remove the duplicate header navigation

## Why
The seven view icons beside Quick Add duplicate sidebar navigation and crowd the header.

## What Changes
- Remove the header view switcher for triage, backlog, board, roadmap, timeline, activities, and synchronization.
- Keep Quick Add, project settings, global search, and active filter chips available.
- Preserve sidebar navigation in expanded and collapsed modes.

## Impact
Only the web header presentation changes. No API, data, configuration, or navigation-state changes are required. Sidebar redesign and new activity indicators are out of scope.
