# #54 implementation and validation

Branch: `feat/54`. Existing PR: https://github.com/sebastienferry/taskflow/pull/95.
Integrated base: `origin/main` at `4ff2e05`.

## Delivered behavior

- `cmd/agent`: owns daemon startup, stdio MCP, Git/worktree operations, skill provisioning, editor/provider execution and consoles. Includes main's new free console, agent log and local diff features.
- `cmd/server`, `internal/db`, `internal/handlers`: retain persisted state, HTTP/MCP and tracker queues; delegate local operations through correlated, connection-bound requests. Server project saves never modify a repository. Legacy server terminal routes return 410.
- `internal/trackerapi`: native GitHub REST/GraphQL and Linear GraphQL with explicit server credentials, paginated lists, structured failure handling and no CLI fallback. Failed creation never invents a remote identity. Jira remains unsupported as on the integrated baseline.
- `internal/agentprotocol`, `internal/agentconfig`, `internal/models`: shared contracts and pure normalization; personal project configuration and instructions remain preserved. Agent evidence restores the server skill editor's divergence view.
- `internal/workspace`: local Git operations preserve existing branches and dirty worktrees instead of resetting/removing them after an error.
- `Makefile`, `desktop/electron`: independent builds/releases and an agent-only desktop resource; direct daemon launch and platform-specific executable resolution.
- README, architecture, API/capability guide, interface contract and ADR 0006: deployment credentials, three-party boundaries and migration.

The old server-local receipt worker and its now-unused private validators are
retired. Current tests cover native MCP transitions, launch/remote-run separation,
agent checkout evidence and failure behavior instead of unused receipt code.
