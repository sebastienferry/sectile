# #71 — Desktop agent log viewer

## Result

The desktop Agent logs toolbar action displays a local snapshot of its existing diagnostic file, including before connection and after startup failure. Refresh replaces the snapshot; missing, empty, truncated and read-error states are explicit. The viewer identifies the source and explains that agents started elsewhere may write to their original terminal.

## Files

- `desktop/electron/agent-log.cjs`: asynchronous, bounded 256 KiB tail reader, regular-file checks, UTF-8 boundary handling, and descriptor cleanup.
- `desktop/electron/main.cjs`: fixed-source `agent-logs` IPC handler, independent of agent/server connectivity.
- `desktop/electron/preload.cjs`: no-argument `agentLogs` bridge.
- `desktop/src/main.js`: persistent toolbar action and read-only dialog with Refresh, source, status and appropriate close label.
- `desktop/src/style.css`: log wrapping, keyboard focus, and panel height that leaves the newest output above the shared footer.
- `desktop/tests/agent-log-reader.ui.cjs`: filesystem and bounded-tail regression coverage.
- `desktop/tests/agent-logs.ui.cjs`: real Electron offline/connected inspection, literal rendering, refresh/recovery, selection preservation and late-response coverage.
- `README.md`, `desktop/README.md`: discoverability and usage guidance.
- `docs/clarifications/71.md`, `openspec/changes/71-local-agent-logs/`: scope, behavior contract, design and checklist.
