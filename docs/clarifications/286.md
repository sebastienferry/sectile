## Restated request and scope

Provide and configure dedicated branded icon assets for the Sectile Desktop application across supported operating systems (macOS, Windows, Linux) and runtime surfaces (packaged application bundle, BrowserWindow window/dock icon, and Vite renderer HTML). This replaces the default Electron icon displayed when packaging or running the desktop application.

Out of scope:
- Redesigning the core Sectile brand identity (the official Sectile stream logo with badge defined in `web/src/components/SectileLogo.tsx` and `web/public/favicon.svg` is adopted as the baseline).
- Modifying backend server logic, database schema, or local agent daemon endpoints.
- Altering the web frontend favicon or logo components.

## Ambiguities, worst first

1. **Source icon design / artwork**:
   - *Ambiguity*: The ticket states "Change icon for Desktop App" with an empty description. Should we adapt the official Sectile stream logo (`SectileLogo.tsx` / `favicon.svg`) into standard multi-resolution desktop icon assets, or does the owner wish to supply a custom or different graphic asset?
   - *Impact*: Directly alters the graphic asset files authored and committed to the repository.
   - *Decision / Recommendation*: Adapt the official Sectile stream logo (`web/src/components/SectileLogo.tsx` / `web/public/favicon.svg`), rendering crisp multi-resolution assets (`.icns` for macOS, `.ico` for Windows, `.png` for Linux/runtime, `.svg` for web/renderer).

2. **In-app UI header branding vs OS application bundle icon**:
   - *Ambiguity*: Does the request solely target the operating system application icon (macOS Dock / Finder, Windows Taskbar, Linux desktop launcher, window icon), or should the Sectile logo also be displayed visually inside the desktop UI header next to "Sectile Desktop"?
   - *Impact*: In-app branding requires modifying `desktop/src/main.js` and `desktop/src/style.css` to add the SVG logo element beside the title.
   - *Decision / Recommendation*: Include both: configure the OS-level application icons and place the official Sectile logo (24px) in the desktop app header next to `<strong id="app-title">Sectile Desktop</strong>`.

3. **Development mode Dock icon on macOS (`npm start`)**:
   - *Ambiguity*: Packaged builds (`desktop/release/Sectile.app`) obtain their icon through `@electron/packager`. However, running from source (`npm start` / `electron .`) on macOS does not automatically inherit packaged `.icns` assets.
   - *Impact*: Without explicit runtime setting in `desktop/electron/main.cjs`, running the desktop app in development on macOS will continue showing the default Electron icon in the Dock.
   - *Decision*: In `desktop/electron/main.cjs`, add `if (process.platform === 'darwin' && app.dock) app.dock.setIcon(iconPath)` when initializing the application.

## Critical dependencies

- Generating binary icon formats (`.icns` and `.ico`) requires tooling such as `iconutil`, `sips`, or graphics conversion libraries. Pre-generated, high-quality multi-resolution binary assets (`icon.icns`, `icon.ico`, `icon.png`, `icon.svg`) will be placed directly in `desktop/assets/` to ensure builds run deterministically on any machine without requiring build-time image conversion dependencies.
- No backend migrations, database changes, or external service dependencies.

## Reversible technical choices resolved via project conventions

- **Asset location**: Place the icon assets in `desktop/assets/`:
  - `desktop/assets/icon.icns`: macOS icon bundle (16x16 up to 1024x1024 with @2x Retina scales).
  - `desktop/assets/icon.ico`: Windows multi-resolution icon (16x16, 24x24, 32x32, 48x48, 64x64, 128x128, 256x256).
  - `desktop/assets/icon.png`: 512x512 high-resolution master PNG for Linux, `BrowserWindow`, and Dock runtime.
  - `desktop/assets/icon.svg`: Vector icon for crisp rendering in HTML and in-app header.
- **Packager configuration**: In `desktop/electron/package.cjs`, set `icon: path.resolve(__dirname, '../assets/icon')` (without extension), allowing `@electron/packager` to select the platform-appropriate icon file automatically.
- **Window and Dock configuration**:
  - In `desktop/electron/main.cjs`, pass `icon: path.join(__dirname, '../assets/icon.png')` to `BrowserWindow`.
  - In `desktop/electron/main.cjs`, set `if (process.platform === 'darwin' && app.dock) app.dock.setIcon(path.join(__dirname, '../assets/icon.png'))`.
- **Renderer favicon**: In `desktop/index.html`, add `<link rel="icon" type="image/svg+xml" href="/assets/icon.svg">`.
