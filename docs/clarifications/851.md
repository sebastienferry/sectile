# Clarification Report - #851

## Round 1 - 2026-10-15

### Request and scope
In the web UI's macro view (the roadmap), a macro's key becomes a link that
opens the macro's own page on its tracker (Jira epic, GitHub milestone, GitLab
epic), in a new tab, the way a task key already does on the task cards. Out of
scope: the data model and the server (the URL is already delivered), the macro
badge on task cards (an in-app navigation, #630), the desktop shell beyond what
it inherits from the shared web components, and macros the tracker gives no
page for.

### Ambiguities
1. Which displays of the macro key become links. Two readings: the row keys
   only, or every display of a macro key in the view (rows, panel header,
   seed table).
2. Whether the panel's existing "Lien" button stays once the header key is a
   link.

### Settled technical choices (reversible, from existing conventions)
- Follow the `TaskCard` idiom: the key itself is the anchor, opens in a new
  tab (`target="_blank" rel="noreferrer"`), carries the `openRemoteTitle`
  tooltip, and stops click propagation so following the link neither selects
  the row nor toggles a multi-selection; a macro without `externalUrl` keeps
  its plain-text key.
- A click on the key therefore opens the tracker instead of selecting the
  macro; the rest of the row still selects it, and drag-and-drop between
  horizons is unchanged.
- Colours, sizes and fonts of the key stay as they are, with a hover
  underline as on task cards.
- The macro badge on task cards (`parentKey`), which takes the user to the
  macro on the roadmap (#630), keeps that behaviour.
- The change is in shared web components, so Sectile Desktop gets it too.
- A user-visible change: one `Changed` line under `## [Unreleased]` in
  `CHANGELOG.md` at implementation.

### Dependencies
None: no migration, no API change, no new tracker call. The URL is the one
the copy-link and "Lien" buttons already use.

### Product questions for the owner
1. Scope: should every display of a macro key in the macro view become a
   link (full row, condensed row, panel header, seed table)?
   **Recommendation:** yes, all four, so a macro key behaves the same wherever
   it appears in the view.
2. The panel's "Lien" button: keep it next to the now-linked header key, or
   remove it as a duplicate? **Recommendation:** keep it; it is the labelled,
   larger target and sits with the "Copier" button.
