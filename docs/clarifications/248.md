## Resolved technical choices (reversible)

- **Ignore rule form:** change root `.gitignore:7` from `node_modules/` to `node_modules`. It matches files, symlinks and directories at any depth, follows the convention already used in `web/.gitignore:10`, and covers `desktop/`, `web/` and any future package in one line. An explicit `desktop/node_modules` entry would fix only one path.
- **Verification:** `git check-ignore -v --no-index desktop/node_modules web/node_modules` must report a rule for both paths, including with a symlink created at `desktop/node_modules`. Then `git clone` into a temporary directory and run `npm ci --prefix desktop` (or `make desktop-deps`) successfully.
- **Commit shape:** a single `.gitignore` change on `feat/248`. History is not rewritten; the symlink blob stays in past commits, which is harmless.
