# Clarification #474 - Add cmd (ctrl) + B to toggle sidebar

Ticket: https://github.com/sebastienferry/sectile/issues/474
Branch: `feat/474`

## Round 1 (2026-09-25)

### Restatement

Pressing Cmd+B on macOS, or Ctrl+B elsewhere, collapses or expands the main
sidebar, exactly as its existing toggle button does. The ticket has no
description beyond its title; out of scope are resizing the sidebar, changing
what the sidebar contains, any other shortcut, and a user-configurable keymap.

### Ambiguities (worst first)

1. **Ctrl+B inside a terminal.** Both clients embed xterm; the desktop one is
   its main surface. Ctrl+B is meaningful there (tmux prefix, readline
   backward-char, "run in background" in Claude Code). Intercepting it breaks
   those; letting it through makes the shortcut dead whenever the terminal has
   focus on Windows and Linux. Cmd+B on macOS has no such conflict.
2. **Which modifier on which platform.** The existing Cmd/Ctrl+K accepts
   either modifier on every platform. Doing the same for B means Ctrl+B on
   macOS also toggles, which on macOS is the terminal key above.
3. **Which clients.** Web and desktop both have a sidebar and a toggle.
4. **Web persistence.** Desktop remembers the collapsed state across restarts,
   web resets it on every reload. A shortcut makes toggling frequent, which
   makes the reset more visible.
5. **Text fields.** The Markdown editor already binds Cmd/Ctrl+B to bold.

### Dependencies

None: no migration, API, server or tracker change. Frontend only, in
`web/` and `desktop/src/`. User-visible, so a `CHANGELOG.md` line under
`## [Unreleased]` / `Added`.

### Technical choices resolved from the code

- **Markdown editor keeps bold.** When the event was already handled
  (`defaultPrevented`), the global handler does nothing; elsewhere, including
  plain inputs where Cmd/Ctrl+B does nothing today, the sidebar toggles.
- **Exact chord only.** Shift and Alt must not be held (Cmd+Shift+B is the
  browser bookmarks bar), and auto-repeat (`event.repeat`) is ignored so a held
  key does not flicker the sidebar.
- **Same code path as the button.** Web calls `setSidebarCollapsed(prev =>
  !prev)`; desktop reuses the button handler (class toggle, re-render of the
  toggle, persistence, `resize()` of the terminal).
- **Renderer listener, not an Electron menu accelerator**, in line with
  Cmd/Ctrl+K: Windows and Linux have no application menu to host it.
- **Discoverability.** The toggle buttons' tooltips name the shortcut, in the
  form the command palette button already uses (`⌘B / Ctrl+B`); the web
  command palette gains a "toggle sidebar" entry showing it.
- **Ignored while a modal dialog is open** (desktop `<dialog>`, web modals):
  the sidebar is behind it, so toggling would be invisible.

### Product questions

1. **Terminal focus.** Recommended: on macOS Cmd+B always toggles, Ctrl+B is
   left to the terminal; on Windows/Linux Ctrl+B toggles except when a
   terminal has focus, where the key goes to the terminal.
2. **Clients.** Recommended: web and desktop, both in this ticket.
3. **Web persistence.** Recommended: remember the collapsed state on web too
   (browser `localStorage`, as desktop does).
