# Clarification #530 - Web i18n: sprint timeline and sprint lifecycle dialogs

Batch #526 to #534; shared decisions D1 to D9 are in `docs/clarifications/526.md`.

## Round 1 (2026-09-26)

### Request

The sprint timeline hardcodes French throughout (timeline labels, batch
creation, edit/start/close/reopen/delete dialogs, unfinished-task destinations,
backlog placement, warnings and feedback), and `lib/sprints.ts` forces `fr-FR`
dates. The whole sprint journey must follow the UI language, dates included,
without touching sprint names, stored dates, time zones or tracker writes.

### Code read

`SprintTimelineView.tsx`, `lib/sprints.ts`, `lib/sprintApi.ts`,
`tests/sprintManagement.test.mjs`.

### Ambiguities

1. `formatDateFR` is replaced by the locale-aware formatter (D4). Stored and
   sent values keep the ISO `YYYY-MM-DD` form of `formatDateISO`.
2. The sprint shorthand "S1" is kept as `S{n}` in both languages: it is a
   compact index, and "Sprint 1" does not fit the timeline header.

### Dependencies

`web/src/lib/i18n.ts` date formatter (#534), delivered first.

### Decisions

Strings go to the `sprints` namespace (D1).
