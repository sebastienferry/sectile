# Clarification: GitHub #260

**Restated request, as filed.** Make the Claude Code hook Sectile installs work
on a Windows workstation. The unattended clarification and specification found
the root cause — the registered command was the path of a `.sh` file, which
`cmd.exe` resolves through its file association, so the hook had never run
there — and PR #263 first ported the hook into the agent binary as a subcommand.

**Redirection (2026-09-21).** After discussion between the maintainers, the
ticket changed direction: the hook system is **removed**, not fixed. Two
reasons, neither of which the port would have changed:

1. It is intrusive. Sectile writes `~/.claude/settings.json`, a user file it
   otherwise only reads, and runs a process on every tool call of every Claude
   Code session on the workstation, launched by Sectile or not.
2. It is not needed. The desktop banner on a finished run comes from the run
   list the agent already owns. What the hook alone added — the waiting mark on
   a run, and a banner for sessions Sectile did not launch — is not worth that
   cost.

**Scope settled with the maintainer.**

- Remove the hook: the installer, the embedded script, the registration merge,
  the `sectile-hook` subcommand from #263, and the agent-side receivers that
  existed only for it (`/control/runs/{id}/waiting`, `/desktop/session-alert`,
  the desktop's session-alert poll).
- Keep the waiting model idle: `waitingSince` on the run, the server route, the
  web indicator and filter, the desktop rendering. Removing it is a change of
  its own, if ever.
- Retire every earlier installation on the next project setup, for every
  provider: scripts through the manifest, registrations by Sectile ownership
  only, third-party hooks and every other key preserved, an unparseable file
  left alone and reported.
- The PR branch is rebuilt from `main` so the diff reads as a removal rather
  than a port followed by its deletion.

The openspec change is `260-remove-claude-hooks`; the withdrawal is recorded in
ADR 0012's last revision.
