# Clarification: #871 — Reserve Orchestration for orchestration agents

## Round 1 — 2026-10-26

### Request and scope

Make Desktop Orchestration membership follow the explicit responsibility of a dedicated orchestration agent and its sessions, excluding ordinary ticket workers even when an orchestrator launched them. Preserve normal execution access, lifecycle, queue and capacity accounting; new orchestration capabilities, scheduling redesign and concurrency changes are out of scope.
