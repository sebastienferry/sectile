## 1. Restated Request and Scope

Rename TaskFlow to **Sectile**, using **sectile** as the lowercase technical slug, following the product owner's explicit selection. Apply the rename across public display branding, executable names, distribution artifacts, frontend package metadata, and current documentation while preserving existing installations and backwards-compatibility aliases.

**Out of scope:**
- Visual design overhaul, new logos, color palettes, or taglines.
- Renaming the remote GitHub repository (`sebastienferry/taskflow`) or the Go module (`tasks`).
- Destructive migration, movement, or deletion of existing user SQLite databases.
- Breaking backwards compatibility with existing environment variables (`TASKFLOW_*`), local configuration paths (`.taskflow/`), or CLI/terminal execution protocols.
- Rewriting historical reports, closed change specifications, or changelogs merely to purge past branding.

## 2. Decisions and Resolved Ambiguities

1. **Replacement Product Name (Settled)**:
   - The product owner selected **Sectile** (technical slug: `sectile`).
   - Root meaning: Derived from *Opus Sectile*, the ancient Roman art of precisely cutting and interlocking distinct stone/marble pieces to form a unified, seamless mosaic. Directly reflects modular agent orchestration and task composition.
   - Display name: `Sectile`.
   - Lowercase slug: `sectile`.
   - Frontend package name: `sectile-web`.
   - Executable binary: `bin/sectile`.
   - Distribution binaries: `dist/sectile-<os>-<arch>`.
2. **Rename Depth & Retained Compatibility Contracts (Settled)**:
   - Retain existing database paths in order: explicit `DB_PATH`, `./tasks.db`, `$APP_DIR/taskflow/tasks.db`, and `$APP_DIR/taskacao/tasks.db`. Do not introduce breaking database paths.
   - Retain existing environment variable support: `TASKFLOW_*` and `TASKACAO_*` environment variables remain supported with existing precedence and behavior.
   - Retain `.taskflow/` configuration directories, JSON schema, and `taskflow:project-context` delimiters in repository instruction files.
   - Retain localStorage keys with fallback reads (`taskflow_*` and `taskacao_*`).
   - Retain health check API service identifier (`taskflow-api`) and machine-facing terminal markers (`__TASKFLOW_*`) to ensure producer/consumer stability.
3. **Repository and Module Coordinates (Settled)**:
   - The Go module remains `tasks`.
   - The Git remote remains `sebastienferry/taskflow`.
   - The working branch remains `47-rename-taskflow-to-something-else`.
