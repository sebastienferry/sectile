# Clarification for GitHub #432 (Add link to the created ticket in the toaster)

Task: `gh-11a4f59c-b6bd-4747-8ea5-0a10d5b78da4-432`

Branch: `feat/432`. Parent macro: M-7 (Ux improvements and fixes).

## Round 1: analysis (2026-09-24)

### Request restated

When Sectile confirms that a ticket was created, the success toast should carry a link
that takes the user to that ticket instead of only printing its key and title. Out of
scope: toasts for updates, moves, deletions and errors, and any change to how tickets
are created on the tracker.

The ticket has no description, so the destination of the link and the creation paths it
covers are open (see the questions below).

### Files read

- `web/src/components/ToastContainer.tsx`: `ToastItem` renders an icon, a title, an
  optional description clamped to two lines, and a close button. It dismisses itself
  after `duration` (3.5 s by default) with no pause on hover. Nothing in it is clickable
  besides the close button.
- `web/src/types/index.ts`: `ToastMessage` is `{ id, type, title, description?,
  duration? }`, text only.
- `web/src/context/AppContext.tsx`: `addToast` (defaults `duration` to 3500 ms) and the
  creation toasts:
  - `createTask` (used by `QuickAddModal`): "Tâche créée", description
    `KEY: title (SOURCE)`. The response is the full `Task`, `externalUrl` included.
  - `cloneTask`: "Story clonée avec succès", same description; it already opens the
    clone in the detail modal by default (`openAfterClone = true`).
  - `createStoryUnderMacro` (Roadmap shaping): "Story créée", `KEY sous MACRO`. The
    response carries `storyKey`, and `task` only when no shaping todo is involved.
  - `createMacro`: "Macro KEY créée", no description.
- `web/src/components/QuickAddModal.tsx`: closes on success and does not open the new
  ticket.
- `internal/db/db.go` (`CreateTask`): remote creation on GitHub/Jira is synchronous, so
  the returned task already holds the tracker key and `externalUrl`.
- `internal/handlers/handlers.go`: the `/macros/{key}/story` endpoint and its two
  response shapes.

### Neighbouring patterns

- Opening a ticket in the app is `setSelectedTask(task)` (the detail modal), as
  `cloneTask` does.
- Tracker links elsewhere open `externalUrl` in a new tab.

### Ambiguities (worst first)

1. **Where the link goes.** Opening the ticket in Sectile's detail modal and opening the
   tracker page (GitHub issue, Jira issue) in a new tab are different code paths and
   different behaviours; local tickets have no tracker page at all.
2. **Which creation toasts get the link.** Quick add only, or also stories created from
   the Roadmap, clones and macros. Story-from-todo responses carry no task, and a macro
   is not a task the detail modal can open, so each path is its own piece of work.

### Critical dependencies

None: no migration, no API change is required for the quick add path. Covering
story-from-todo would need either a refetch by key or the endpoint to return the task.

### Resolved technical decisions (reversible, settled here)

- **D1: Toast action.** `ToastMessage` gains an optional action (label + callback, or an
  href for an external link); `ToastItem` renders it as a link-styled button. Other
  toasts are unchanged.
- **D2: Time to click.** A toast carrying an action stays longer (8 s) and pauses its
  auto-dismiss while hovered, so the link can actually be reached.
- **D3: Clicking the in-app link** closes the toast.
- **D4: Wording.** The link text follows the toast's current language via the existing
  `t.toasts` translations (French and English).

### Product questions (awaiting the owner)

1. **Link destination.** Recommended: **(C)** the ticket key opens the ticket in
   Sectile's detail modal, and an external-link icon next to it opens the tracker page
   when the ticket has one. Alternatives: (A) in-app only; (B) tracker page only, no
   link for local tickets.
2. **Covered creation paths.** Recommended: **quick add and Roadmap stories**; clones
   already open the new ticket, and macros have no detail view. Alternatives: quick add
   only; every creation toast including macros (tracker milestone/epic link).

### Status
