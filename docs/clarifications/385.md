# Clarification: issue detail content hierarchy

## Round 1 — 2026-09-23

The WebUX issue detail should show a full-width title, immediately followed by description and technical context on the left and metadata on the right, then pull requests below both columns. This changes presentation only, preserving existing fields, actions, persistence and tracker availability rules.

### Evidence

Read `web/src/components/TaskDetailModal.tsx`, `web/src/components/Markdown.tsx`, `web/tests/pullRequestLinks.test.mjs`, `web/tests/condensed-card.browser.mjs`, `web/package.json`, `Makefile`, `AGENTS.md` and `.agents/MEMORY.md`.

The Story tab currently renders title, two metadata grids, pull requests, the combined Description & Technical Context editor, then labels. Panel and modal share `renderStoryInfoSection`. The editor already combines description and technical context; no new field or split editor is needed. Creator is conditional on an existing value and Team is Jira-only. Those rules remain.

### Settled decisions

- The user's final layout, approved before requesting pickup, is the contract.
- Keep the combined description editor and all rewrite controls together in the left column.
- Group all twelve requested metadata fields on the right, retaining their conditional visibility and handlers.
- Keep the title and pull request list full width above and below that area respectively.
- Use a responsive layout: stack description before metadata where two columns cannot fit; preserve reading and keyboard order.
- Apply the shared layout to panel and modal details; leave other tabs and workflow behavior alone.
- No backend, schema, API, dependency or architecture change is required.

### Open questions and exit condition

No open product questions. The owner explicitly requested autonomous clarification, specification and implementation after approving the story, and then ended the voice session. The unattended pickup exit condition is met. Reversible spacing and breakpoint choices will be verified against the existing UI.
