# Clarification — GitHub #567: User guide in /docs

## Round 1 — 2026-09-27

The request is to add a task-oriented user guide under `/docs` for signing in, connecting a workstation, configuring Jira, setting up projects, using Claude Code prompts and autonomous runs, and working in Sectile Desktop. Product changes, deployment instructions, and a replacement for the existing engineering or Desktop reference documents are out of scope.

## Evidence reviewed

- `README.md` and `docs/README.md`: current entry points and technical documentation index.
- `desktop/README.md`: pairing, project configuration, task launch, workflow actions, and Desktop controls.
- `web/src/lib/session.ts`, `web/src/lib/trackers.ts`, and `internal/handlers/usercredentials.go`: personal tracker credential and sealing behavior.
- `.agents/MEMORY.md`: current project constraints around personal Jira credentials and server credentials.

## Settled scope and decisions

1. Write the guide in English, organized by user journey and linked from both documentation indexes. Keep the current French UI labels where quoting controls, while explaining them in English.
2. Cover every topic in the ticket with verified steps and links to the existing detailed references. Treat “WebUx” as the browser interface.
3. Explain the difference between a personal Jira token, its optional sealing passphrase, and a server credential used for unattended work. Never suggest putting a token in a prompt or workstation setting.
4. Explain both opening an existing project and creating/configuring a new one, including the separate workstation folder mapping needed for local runs.
5. Explain manual prompts in Claude Code and the built-in full pickup action as distinct user paths. Do not promise that a prompt alone changes the board stage.
6. Keep the guide focused on supported present behavior. Use placeholders for URLs, paths, and credentials; no real secrets or deployment-specific values.

## Ambiguities and dependencies

- The ticket does not name a target audience or platform. The guide will address a signed-in user with access to a Sectile server and a workstation; OS-specific installation remains in `desktop/README.md`.
- The exact screen labels can evolve. The guide will favor the current labels in source and link to the maintained technical reference for detail.
- A live Jira account, server, and paired workstation are external prerequisites for end-to-end use; documentation validation can check source consistency and links without requiring them.

## Open product questions

None. The listed topics and current product behavior determine the guide's acceptance criteria without changing product behavior.
