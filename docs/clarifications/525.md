# Clarification #525 - Desktop list of runs per task

Ticket: https://github.com/sebastienferry/sectile/issues/525
Branch: `feat/525`

## Round 1 (2026-09-26)

### Request

The desktop toolbar shows the executions of the selected task in a drop-down
(`#execution-history`) that renders as a boxed control, heavier than the icon
buttons next to it; the owner wants it visually lighter. Out of scope: the web
app, the other `<select>` elements of the desktop (dialogs, ticket compose),
the sidebar task rows, and the rules deciding which runs are listed.

### Code read

- `desktop/src/main.js`: toolbar markup (line 42) and the history rendering in
  `render()` (around line 618). The select lists every run sharing the selected
  run's task key, oldest first, each option labelled `N · skill · status`, and
  is hidden when the task has fewer than two runs.
- `desktop/src/style.css`: the global `select` rule (surface background,
  `--border-strong` border, 6px radius, 8px padding, 8px left margin),
  `#execution-history{max-width:170px}`, `.toolbar-actions>select`, and the
  `.icon-button` rules (transparent background, `--hover-bg` on hover, accent
  focus ring) that the neighbouring controls use.
- UI tests touching the control: `desktop/tests/console.ui.cjs`,
  `free-console.ui.cjs`, `task-header.ui.cjs`, `next-step.ui.cjs`,
  `discussion-header.ui.cjs`, `task-order-render.ui.cjs`.

### Ambiguities (worst first)

1. **Restyle or replace.** Lightening the native `<select>` is a CSS change;
   replacing it with a custom menu (popover with status icons, dates) is a new
   component with keyboard handling and rewritten tests.
2. **Option content.** Keep `N · skill · status`, or change what each entry
   says (status icon, date, duration).

### Dependencies

None: no server, API or migration change. The desktop UI tests need a
`npx vite build` first.

### Technical choices resolved from the code

- Style only `#execution-history`; the global `select` rule stays as it is.
- Reuse the existing theme tokens (`--hover-bg`, `--accent`, `--text-muted`)
  so light and dark themes both follow; no new colour.
- Keep the visibility rule (hidden under two runs) and the ordering.
- A user-visible change: the pull request adds a `Changed` line under
  `## [Unreleased]` in `CHANGELOG.md`.

### Product questions

1. Restyle the native select (ghost look like the icon buttons: no border or
   background at rest, background on hover, discreet chevron) or replace it
   with a custom menu? **Recommended: restyle the native select.**
2. Keep the option labels `N · skill · status` unchanged? **Recommended: keep
   them.**
