# Clarification — #558: the adjustment contract carries guardrails only

## Round 1 — 2026-09-27

### Request restated

Reduce `runner.AdjustmentContract`, the text appended to every adjustment
prompt, to guardrails and the feedback rule, so that whether a skill reviews,
corrects, runs checks and pushes becomes the skill's own decision. The bundled
`adjust-issue` skill, the built-in fallback prompt and the server-side stage
gates are out of scope and do not change.

### Evidence and settled facts

- The contract is appended in two places: `internal/runner/runner.go`
  (managed runs, after the resolved prompt template) and
  `internal/agent/agent_config.go` `dispatchCommand` (native launches, after
  the skill command). Both use the same constant, so one edit covers both.
- The built-in fallback prompt (`runner.go`, `case "adjust"`) spells out the
  whole work itself — reconcile, review, fix, build/lint/test, commit, push,
  verify readiness. Trimming the contract therefore leaves the fallback
  behaviour identical.
- The bundled skill fragments (`internal/skills/fragments/adjust/steps.md`,
  `guard.md`) also carry the whole work, so the default behaviour is kept.
- The server-side gates (forge-confirmed PR, non-draft when open, head equal
  to the checkout commit, clean checkout; ADR 0004 and ADR 0009) do not read
  the contract text and are untouched.
- `TestNativeAdjustmentAliasesAndReconciliation` only asserts that the
  contract is present (`Never create or replace a PR`); no golden file embeds
  the contract.

### Ambiguities resolved from the code (reversible)

1. **Which sentences are guardrails.** Kept: verify the matching PR (open or
   merged by the human); never push onto a merged PR, report its final state;
   never create or replace a PR; missing-PR recovery belongs to the earlier
   creation stage; retrieve available feedback and record a disposition for
   each, retrieval failure blocks completion, no human feedback is required;
   preserve work on failure; never merge, approve, close the task or remove
   its worktree. Removed: reviewing the branch against the specification,
   reconciling the default branch, running build/lint/test, committing,
   pushing, updating the PR and verifying readiness. "Preserve work" and
   "missing-PR recovery" restrict what the agent may do rather than prescribe
   work, so they stay.
2. **Test shape.** Extend the existing native-dispatch test with negative
   assertions on the removed prescriptions, and add a runner-level test that
   the managed prompt of an installed skill carries the guardrails and not the
   work.
