# Clarification #548 - Fix the French title in comments

Ticket: https://github.com/sebastienferry/sectile/issues/548
Branch: `feat/548`

## Round 1 (2026-09-26)

### Restatement

Stage-transition reports for clarification and specification currently add
French tracker-comment headings. Those two headings must be English so reports
created by the English-language development workflow have English titles.

The report body, other stage headings, user-facing French runtime strings, and
the stage-transition workflow itself are out of scope.

### What already exists

`internal/db/trackerops.go` formats every report comment in one switch over
the completed stage. Its `clarified` and `specified` cases alone are in scope:
they currently select French headings before the stage note is posted through
`AddTaskCommentAs`.

### Ambiguities and dependencies

None. The ticket names both affected workflow stages and the expected language.
The change has no migration, external-service, or data dependency.

### Settled decisions

- Translate only the `clarified` and `specified` tracker-comment headings.
- Preserve the existing emoji, Sectile prefix, Markdown structure, and note
  body unchanged.
- Add focused automated coverage of the generated headings.

### Open product questions

None.

### Exit condition

Met. The requested wording and scope are explicit, so clarification can move
to the specification stage without further owner input.

## Final delivered scope (2026-09-27)

PR #549 expanded the final implementation to five completed stages:
`clarified`, `specified`, `implemented`, `reviewed`, and `finished`. Each newly
generated tracker report uses an English heading. The report body, existing
posted comments, and other French runtime strings remain unchanged. This
section records the delivered scope without changing the original Round 1
decision history.
