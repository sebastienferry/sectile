## Round 1 (2026-09-26)

### Request

The web shell and the board still show French labels, tooltips and accessible
names while the UI language is English: the sidebar, the project picker, the
pinned bar, the board and backlog controls, card menus, filters, the command
palette, the display scale menu and the status bar. Every Sectile-owned string
of those surfaces must follow the selected language, singular and plural counts
included.

Out of scope: tracker-owned column names and statuses, user-authored task
content, the quick-add dialog (#455), the task detail (#527) and the other
companion tickets, and the native desktop UI.

### Code read

`web/src/locales/translations.ts` (the catalog: one `TranslationSchema`, `fr`
and `en`, exposed as `t` by `useApp()`), `web/src/context/AppContext.tsx`
(`t` derived from `settings.language`, default `fr`), `web/src/App.tsx`,
`web/index.html`, `Sidebar.tsx`, `Header.tsx`, `PinnedBar.tsx`, `BoardView.tsx`,
`ListView.tsx`, `TaskCard.tsx`, `TaskFilters.tsx`, `CommandPalette.tsx`,
`DisplayScaleMenu.tsx`, `StatusBar.tsx`, and the browser tests that assert
French accessible names through `t: translations.fr`
(`tests/condensed-card.browser.mjs` and its neighbours).

Neighbouring solution: the profile modal and the navigation labels already use
the catalog (`tests/profileModal.test.mjs`, `tests/navigationViews.test.mjs`),
with ad hoc `{placeholder}` replacement.

### Ambiguities

1. Which headings are tracker-owned. A column named by the tracker keeps its
   name; the headings Sectile invents when a value is missing ("Non classé",
   "Sans parent", stage names of Sectile's own workflow) are translated.
2. Plural forms. The catalog has none; "3 tâches" was built by string
   concatenation. Two readings (keep concatenation, or plural rules) give
   different code: settled by D3.

### Dependencies

None outside the web client. No API, migration or server change.

### Batch decisions (settled, reversible)

- **D1 - Catalog layout.** The existing catalog stays the single source,
  exposed as `t`. The strings this batch adds live in one module per surface
  under `web/src/locales/` (`shell`, `taskDetail`, `projectSettings`,
  `planning`, `sprints`, `skillsEditor`, `operations`, `signIn`), each
  exporting `{ fr, en }` with `en` typed after `fr`, and merged into
  `translations` as new namespaces. Reason: the catalog would pass 6 000 lines,
  and a missing English key must fail `tsc`, not show `undefined`.
- **D2 - Interpolation.** `format(template, params)` in `web/src/lib/i18n.ts`
  replaces every `{name}`; existing `.replace('{x}', …)` call sites stay as
  they are unless touched.
- **D3 - Plurals.** `plural(locale, count, { one, other })` built on
  `Intl.PluralRules`. French treats 0 and 1 as singular, English only 1.
- **D4 - Dates and numbers.** Shared formatters in `web/src/lib/i18n.ts` take
  the UI locale (`fr-FR` or `en-US`), never the browser's. A date-only value
  (`YYYY-MM-DD`) is read as a calendar date, not as UTC midnight; an invalid
  or missing value renders a neutral placeholder. Owned by #534.
- **D5 - Document language and title** follow the UI locale, at startup and on
  every switch. Owned by #534.
- **D6 - Pre-authentication locale.** The last UI language is remembered in
  the browser (`localStorage`), falling back to the browser language (French
  when it starts with `fr`, English otherwise). The sign-in screen offers a
  French/English switch. After sign-in the personal preference wins and
  refreshes the remembered value. Owned by #533.
- **D7 - Server-generated activity text** is rendered in the viewer's locale
  by a web-side catalog of the known server templates, falling back to the raw
  text. No API or storage change. Owned by #532, recorded in an ADR.
- **D8 - French wording is kept.** The French catalog values reuse today's
  French strings verbatim, so the French UI does not change and the existing
  French browser assertions keep passing.
- **D9 - Changelog.** One user-facing `Fixed` line for the translated screens
  and one for the document language and sign-in locale, both referencing the
  batch issues.
