state, custom/divergent/missing indicators, macro skill labels, the editor
placeholder, reset/save feedback and update metadata; the navigation tooltip

Markdown, prompts, commands, skill IDs and generated documentation stay
unchanged.

`tests/skillLaunchMode.test.mjs`.

2. The Skills navigation tooltip lives in `Sidebar.tsx`, owned by #526, which
