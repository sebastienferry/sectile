The test at line 54 fails with `ERR_UNSUPPORTED_DIR_IMPORT`: the child interprets the raw `#553` path suffix as a URL fragment and attempts to import the worktrees directory. This occurs before the child's formatter calls and time-zone assertions.

Neighbouring browser tests distinguish filesystem paths from URL strings, using `pathToFileURL(...).href` where a filesystem path must become a URL.
